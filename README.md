# Money Transfer System

Система денежных переводов между пользователями. Реализован поэтапно: от базовых структур до конкурентной обработки транзакций с защитой от гонок данных.

## Запуск

```bash
git clone <repo-url>
cd moneyTransferSystem
go run main.go
```

Для проверки гонок данных:

```bash
go run -race main.go
```

## Версии

### v1 - Базовые структуры и операции

Определена структура `User` с полями `ID`, `Name`, `Balance`. Реализованы методы `Deposit` (пополнение) и `Withdraw` (снятие). Метод `Withdraw` возвращает `error` при нехватке средств - идиоматичный способ обработки ошибок в Go.

### v2 - Платёжная система и транзакции

Добавлены структуры `Transaction` и `PaymentSystem`. `PaymentSystem` хранит пользователей в `map[string]*User` (указатели, чтобы методы с pointer receiver корректно изменяли баланс) и очередь транзакций в слайсе. Реализованы методы `AddUser`, `AddTransaction` и `ProcessingTransactions`.

### v3 - Горутины и каналы

Транзакции обрабатываются конкурентно через канал `chan Transaction`. Добавлена функция-воркер `Worker`, которая читает транзакции из канала через `range`. Несколько воркеров запускаются через `sync.WaitGroup.Go`, канал закрывается после отправки всех транзакций - воркеры завершаются автоматически.

### v4 — Защита от гонок данных

В структуру `User` добавлен `sync.Mutex`. Методы `Deposit` и `Withdraw` блокируют мьютекс в начале и снимают через `defer` - это гарантирует разблокировку даже при раннем возврате из функции. Проверка баланса в `Withdraw` выполняется внутри лока, чтобы исключить TOCTOU (time-of-check to time-of-use).
